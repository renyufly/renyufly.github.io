## 第一章.强化学习介绍

强化学习（RL）是一种机器学习方法：让智能体（Agent）通过不断尝试动作、观察结果、获得奖励，并从经验中学习如何做出更好的决策。 

学习应该做什么 (learning what to do) — 学习如何根据不同的情况选择相应的动作，从而最大化一个数值形式的奖励信号 (maximize a numerical reward signal)。

- Learning by Trial and Error（通过试错来学习）
- delayed reward （延迟奖励）：一个动作不仅可能影响当前奖励，还可能影响未来的状态和奖励

| 监督学习（Supervised Learning） | 无监督学习 Unsupervised Learning | 强化学习（Reinforcement Learning） |
| ------------------------------- | -------------------------------- | ---------------------------------- |
| 带正确答案的数据                | 没有标签的数据                   | 与环境交互得到的奖励               |
| 正确标签或目标值                |                                  | 奖励信号 reward signal             |
| 学会准确预测                    | 发现隐藏结构                     | 学会做出高回报的**决策**           |

> 强化学习不是无监督学习的一种，强化学习的目标是最大化奖励，而无监督学习主要是发现数据结构。

| Exploration（探索）    | Exploitation（利用）                                         |
| ---------------------- | ------------------------------------------------------------ |
| **尝试不熟悉**的动作   | 选择**当前estimated value最好**的动作 - **贪心动作（greedy actions）** |
| 目的是**获得更多信息** | 目的是获得较高奖励                                           |
| 可能暂时损失奖励       | 可能错过真正更好的动作                                       |

- Agent 与 Environment 持续交互
- Actions 会影响未来的 State
- Agent 必须考虑 Delayed Consequences（延迟后果）：正确决策有时需要 Foresight（预见）或 Planning（规划）
- 环境存在 Uncertainty（不确定性），Agent 需要持续监测环境，并根据实际情况调整行为

强化学习的主要组成要素：

- Agent (智能体)

- Environment

- Policy（策略）$\pi$ ：决定 Agent 下一步采取什么动作 — 定义了学习智能体在某一时刻的行为方式。是一种从环境状态（State）到动作（Action）的映射关系。

  - 确定性策略（Deterministic Policy）：$a=\pi(s)$

  - 随机策略（Stochastic Policy）：为每个动作指定一个选择概率。
  
- Reward Signal（奖励信号）：告诉 Agent 眼前什么是好的 — 定义了强化学习问题的目标。环境在每个时间步向 Agent 返回一个数值，叫 Reward（奖励）。Reward Signal 是改变 Policy 的主要依据。

- Value Function（价值函数）：从长期来看什么是好的。 Value：从当前状态出发，未来预计能够累计获得多少奖励。 但Value 比 Reward 更难确定，Reward 通常由环境直接给出，而Value 需要根据长期观察和经验不断估计。

  > 所有强化学习算法中，最重要的组成部分之一，就是如何高效地估计 value。
  >
  > 但解决强化学习问题并不一定必须估计 Value Function；例如：Genetic Algorithms（遗传算法）、Genetic Programming（遗传编程）、Simulated Annealing（模拟退火）可以直接寻找表现较好的策略，而不必计算每个状态或动作的 Value。 [直接搜索 Policy：测试多个完整策略，保留表现较好的策略，并产生新的策略继续搜索]
  >

- Model of the Environment（环境模型）：一种模拟环境行为的机制，使 Agent 能够推断环境将如何变化。 能够给定当前状态和动作，预测下一状态和奖励。

- state（状态）：Agent 当前掌握的环境信息，告诉 Agent 当前情况如何。 state 是策略（Policy）和价值函数（Value Function）的输入，同时也是环境模型（Model）的输入和输出。

| State Value                                                  | Action Value                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| $v_\pi(s)$                                                   | $q_\pi(s,a)$                                                 |
| 现在处于状态 s ，如果按照策略 $\pi$ 行动，未来预计总共能获得多少奖励 | 现在处于状态 s ，如果先指定执行动作 $a$，然后按照策略 $\pi$ 行动，未来预计总共能获得多少奖励 |

> 区别在于： 有没有指定当前第一步的动作

| Model-Based RL             | Model-Free RL                      |
| -------------------------- | ---------------------------------- |
| 可以预测未来并规划         | 直接从交互经验中学习               |
| 先模拟可能结果，再决定动作 | 尝试动作，观察奖励，更新策略或价值 |
| 依赖环境模型进行决策       | 不依赖环境模型进行决策             |







强化学习区别于其他学习的最重要特征：它使用的训练信息是对已经采取的动作进行**评价（evaluative feedback）**，而不是通过给出正确动作来进行**指导（instructive feedback）**。使得强化学习需要主动探索（active exploration），即明确地寻找好的行为方式。

> 评价性反馈只能告诉我们已经采取的动作有多好，不能告诉这个动作是否是 最好 或 最差的。

不涉及情境关联的环境被称为**非关联性环境（nonassociative setting）**：智能体 Agent 不需要学习如何在多种不同的情境下采取行动。

非关联任务（nonassociative tasks）：不需要将不同的动作与不同的情境联系起来。在这些任务中，如果问题是平稳的，学习者就尝试找到一个最优动作；如果问题是非平稳的，学习者就尝试跟踪随时间变化的最优动作。



## 第二章.Multi-armed Bandits 多臂赌博机

> 名字来源于赌场里的老虎机（Slot Machine）: 传统老虎机有一个操作手柄（Arm），玩家拉动手柄后，机器会随机给出奖励。 它被称为 One-Armed Bandit（独臂强盗）— 因为老虎机通常让赌场赚钱、玩家输钱。
>
> Multi-Armed Bandit 可以想象为有多个手柄的老虎机，每个手柄对应不同的奖励概率或奖励分布。玩家不知道哪个手柄最好，只能通过不断尝试来学习。

Reinforcement Learning（强化学习）中，Multi-Armed Bandit 是一种简化的序贯决策问题。

假设有 $k$ 个动作：$A=\{1,2,\ldots,k\}$ ，每个动作都有一个未知的真实价值：$q_*(a)=\mathbb E[R_t\mid A_t=a]$

其中：

- $A_t$：在时间 $t$ 选择的动作。

- $R_t$：选择动作后获得的奖励。

- $q_*(a)$：动作 $a$ 的真实期望奖励。

  > $q_*(a)$ 不是某一次选择动作 $a$ 得到的奖励，而是**多次选择这个动作时，奖励的理论平均值**。 每次的奖励可能不同，但长期平均值趋向一个值。

- $Q_t(a)$ ：根据目前的信息得到的估计。目的是 $Q_t(a)\longrightarrow q_*(a)$

智能体（Agent）的目标是：

反复地从 $k$ 个不同的选项（Action）中做出选择，在某段时间内，使获得的**期望总奖励最大化**。

> 只选择当前估计看起来最好的动作，不一定能获得最大的长期总奖励。为了发现真正更好的动作，智能体必须在探索与利用之间进行权衡。

> 经典 Multi-Armed Bandit 不考虑状态转移。动作只影响当前获得的奖励，不会改变下一步所处的环境状态。
>
> 假设每个动作的奖励来自一个平稳 （stationary）概率分布：同一个动作的奖励分布不会随着时间变化。

必要元素：

- Arm（臂）原指老虎机上的操作手柄，在强化学习 中则表示 一个可以选择的动作（Action）
- Action：选择某个 Arm 的行为
- Reward：选择后获得的奖励
- Action Value（动作价值）：选择某个action后，预期能够获得多少奖励 value

| True Action Value | Estimated Action Value     |
| ----------------- | -------------------------- |
| $q_*(a)$          | $Q_t(a)$                   |
| 真正的期望奖励    | 根据过去观察估计的平均奖励 |
| 通常未知          | 可以通过数据计算           |

**动作价值方法（action-value methods）**：如何估计Action的价值 $Q_t(a)$，以及如何利用这些估计值来决定选择哪个Action。

估计action value的方法：

**样本平均法（sample-average method）**：每个估计值都是相关奖励样本的平均值
$$
Q_t(a)= \frac{\text{在时间 }t\text{ 之前选择 }a\text{ 所获得的奖励总和}} {\text{在时间 }t\text{ 之前选择 }a\text{ 的次数}} = \frac{\displaystyle\sum_{i=1}^{t-1}R_i\cdot\mathbb{1}_{A_i=a}} {\displaystyle\sum_{i=1}^{t-1}\mathbb{1}_{A_i=a}}
$$
其中，指示函数 $\mathbb{1}_{A_i=a}$ 表示：如果条件 $A_i=a$ 为真，其值为 1；否则为 0。

如果分母为零，那么将 $Q_t(a)$ 定义为某个默认值，例如 0。

注意：只使用时间步 t **之前**的数据，不包含第 t 步尚未获得的奖励。

> 适用于**平稳赌博机问题（stationary bandit problems）**，奖励的概率分布不会随着时间变化的问题

增量式实现来优化  $Q_t(a)$ 的计算过程：用 $R_i$ 表示第 $i$ 次选择这个动作后获得的奖励，用 $Q_n$ 表示该动作已经被选择 $n-1$ 次之后的价值估计：   ($Q_n$ 是在处理第 $n$ 个奖励**之前**的估计)
$$
Q_n=\frac{R_1+R_2+\cdots+R_{n-1}}{n-1} =\frac{1}{n-1}\sum_{i=1}^{n-1}R_i \\
=> Q_{n+1}=Q_n+\frac{1}{n}[R_n-Q_n]
$$
即使 $n=1$，这个公式也成立。都有： $Q_2=R_1$ 。 $\frac{1}{n}$ 是 步长参数（step-size parameter），一般 用 $\alpha_t(a)$ 表示。

更一般的更新形式： $\text{Target}-\text{OldEstimate}$ 为估计误差
$$
\text{NewEstimate} = \text{OldEstimate} + \alpha \left[ \text{ Target}-\text{OldEstimate} \right]
$$


几种Action Selection 规则：

- **Greedy** 选择： $A_t=\arg\max_a Q_t(a)$。 其中，$\arg\max_a$ 表示使后面表达式取得最大值的动作 $a$。如果出现相同值，则可任选一个。  选择具有最高估计价值的动作。

  > 始终利用当前已有的知识，以最大化即时奖励。它完全不会花时间尝试那些看起来较差的动作，去判断它们实际上是否可能更好

- **ε-greedy** methods：大多数时候采取贪心行为，但偶尔进行随机探索。以一个很小的概率 $\varepsilon$，不根据动作价值估计，而是从所有动作中以相同的概率随机选择一个动作。

  > 选择最优动作的概率最终会收敛到一个大于 $1-\varepsilon$ 的值，也就是，接近于确定地选择最优动作。但只是**渐近保证（asymptotic guarantees）**。
  >
  > ε 是进入随机探索分支的概率，不一定是最终选择非贪心动作的概率。因为在随机探索时，所有动作都有可能被选中，包括贪心动作本身。

  > ε-贪心动作选择会强制尝试非贪心动作，但这种尝试是**不加区分的**
  >
  > 更好的做法是，根据非贪心动作实际上成为最优动作的潜力来选择它们。

- **UCB: Upper-Confidence-Bound Action Selection**（置信上界动作选择）：公式中的平方根项可以看作对动作 \(a\) 的价值估计的不确定性或方差的一种度量。因此，实际上是在最大化一个可以理解为动作 \(a\) 的真实价值可能达到的**上界**的量，其中参数 \(c\) 控制置信水平。每当动作 \(a\) 被选择一次，我们就认为它的不确定性有所降低。  UCB 不会盲目探索，而是更倾向于探索那些**可能成为最优动作、但目前证据还不充分**的动作。

  同时考虑：

  - 当前价值高不高 \(Q_t(a)\)
  - 对这个价值有多不确定：\(c\sqrt{\ln t/N_t(a)}\)

  最终所有动作都会被选择；不过 估计价值较低或已被频繁选择的动作，其被选择的频率会随时间推移而降低。
  $$
  A_t=\arg\max_a\left[ Q_t(a)+c\sqrt{\frac{\ln t}{N_t(a)}}  \right]
  $$

其中：

- \(\ln t\) 表示 \(t\) 的自然对数。  一个长期没有被尝试的动作，会逐渐重新获得探索吸引力。
- \(N_t(a)\) 表示在时间步 \(t\) 之前，动作 \(a\) 已经被选择的次数。
- \(c>0\) 是一个控制探索程度的参数。 \(c\) 较大：更重视不确定性，探索更多； \(c\) 较小：更重视当前价值估计，利用更多。

如果 \(N_t(a)=0\)，那么我们将动作 \(a\) 视为一个使表达式取得最大值的动作。

> UBC 存在的问题：难以处理非平稳问题；难以处理大规模状态空间。

- **Gradient Bandit Algorithms**（梯度赌博机算法）：不再先估计动作价值 \(Q_t(a)\)，**而是直接学习每个动作被选择的概率。**

  考虑为每个动作 \(a\) 学习一个 偏好分数（preference）：\[ H_t(a)\in\mathbb R \] ， 偏好值 H 越大，该动作被选择的频率就越高。但并不表示预期奖励。 **算法学习的是动作之间的相对偏好**。

  动作选择概率由 **softmax 分布**（也称 Gibbs 分布或 Boltzmann 分布）决定：
  $$
  \large \Pr\{A_t=a\} = \frac{e^{H_t(a)}}{\sum_{b=1}^{k}e^{H_t(b)}} =\pi_t(a)
  $$

其中，

- \[ \pi_t(a) \]表示在时间步 \(t\) 选择动作 \(a\) 的概率。
- 初始时，所有动作的偏好值都相同 \[ H_1(a)=0,\qquad \forall a \] ，因此，所有动作最初被选择的概率也相同。

  每个时间步，选择动作 \(A_t\) 并获得奖励 \(R_t\) 后：

  - 对于**本次选择的动作**：$H_{t+1}(A_t) = H_t(A_t) + \alpha(R_t-\bar R_t) [1-\pi_t(A_t)]$
  - 对于**其他未选择的动作**：$H_{t+1}(a) = H_t(a) - \alpha(R_t-\bar R_t)\pi_t(a), \quad a\ne A_t$
  

其中：
- \(\alpha>0\) 是步长参数；
- \(\bar R_t\in\mathbb R\) 是时间步 \(t\) 之前获得的奖励的平均值；如果当前奖励高于基线\(\bar R_t\) ，则未来选择 \(A_t\) 的概率就会增加。

> 梯度赌博机算法 可被视为梯度上升的随机近似。因此，该算法属于随机梯度上升。



一个简单的赌博机算法（A simple bandit algorithm）：使用增量式计算的样本平均值来估计动作价值，并使用 $\varepsilon$-贪心方法选择动作

```sh
# 初始化，对每个动作 a = 1, ..., k：
    Q(a) ← 0
    N(a) ← 0

# 不断重复：
    以概率 1 - ε：
        A ← argmax_a Q(a)（并列时随机选择）
    以概率 ε：
        A ← 从所有动作中随机选择

    R ← bandit(A)
    N(A) ← N(A) + 1
    Q(A) ← Q(A) + [R - Q(A)] / N(A)
```

> 这一步只选择了动作 $A$，因此也只观察到了动作 $A$的奖励。对于没有被选择的其他动作，我们没有获得新的奖励信息，所以它们的样本平均估计保持不变。

针对 非平稳的（nonstationary）强化学习问题，让最近获得的奖励比很久以前的奖励拥有更大的权重：

**固定步长法** — 估计action value：使用一个固定的步长参数（constant step-size parameter）
$$
Q_{n+1}=Q_n+\alpha[R_n-Q_n]
\\ => Q_{n+1} =(1-\alpha)^nQ_1+ \sum_{i=1}^{n}\alpha(1-\alpha)^{n-i}R_i
$$
其中，步长参数 $\alpha\in(0,1]$ 是一个常数。

使用固定步长后，$Q_{n+1}$ 实际上是过去奖励和初始估计值 $Q_1$ 的一个**加权平均值**。

这种方法有时称为**指数近因加权平均（exponential recency-weighted average）**：由于 $1-\alpha$ 小于 1，随着中间间隔的奖励数量增加，分配给 $R_i$ 的权重会逐渐减小。事实上，权重会随着指数 $n-i$ 的增加而**指数衰减**。

如果 $1-\alpha=0$，那么所有权重都会分配给最新奖励 $R_n$，这里采用 $0^0=1$ 的约定。

> 令 $\alpha_n(a)$ 表示在第 $n$ 次选择动作 $a$ 后，处理相应奖励时使用的步长参数。
>
> 如果选择：$\alpha_n(a)=\frac1n$ ，就得到了样本平均法
>
> 如果 $\alpha_n(a)= \alpha$ ， 就是 固定步长法

- $\alpha$ 较大 ：对新奖励反应快，但容易受到随机噪声干扰，估计波动更大
- $\alpha$ 较小 ：估计较平滑，但对真实价值变化的反应较慢



初始化方法 (Initialization)：

Optimistic Initial Values（乐观初始值）：即使始终使用 Greedy 动作选择，也可以通过设置较高的初始action value $Q_1(a)$，让 Agent 主动探索。 

因为 无论最初选择哪个动作，获得的奖励通常都会低于其初始估计值。agent 对得到的奖励感到“失望”，于是转而选择其他动作。结果就是，在价值估计收敛之前，所有动作都会被尝试多次。

> 是一种简单的技巧，在平稳问题中可能相当有效，但它远远算不上是一种普遍适用的探索方法。
>
> 任何特别强调初始条件的方法，都不太可能适用于一般的非平稳问题。**时间的起点只有一次，因此我们不应该过分关注它。**



**Associative Search (Contextual Bandits)（关联搜索 / 上下文赌博机）**

之前的多臂赌博机研究：面对同一组动作，应该选择哪个动作才能获得更高的奖励。

现在，如果不同情境下的最优动作不同，Agent 应该如何根据当前情境选择动作。

在一般的强化学习任务中，存在不止一种情境，而学习目标是学到一个策略（policy）：它是一个从情境到相应最优动作的映射。

关联搜索任务（associative search task）通常被称为 **Contextual Bandits（上下文赌博机）**，处于普通 \(k\) 臂赌博机问题和完整强化学习问题之间。

既需要学习一个策略，又每次动作只影响即时奖励（immediate reward）。

> 如果 当前动作 影响 未来的状态和奖励，就得到了完整的强化学习问题。

在 Contextual Bandit 中，**同一个动作在不同情境下可能有不同的价值**。

> 同一组动作，不同情境下有不同的最优选择。
>
> 根据情境选择动作，动作只影响当前奖励。

因此，需要考虑：
$$
Q(s,a)
$$
其中：

- \(s\)：当前情境（context）；
- \(a\)：可选择的动作；
- \(Q(s,a)\)：在情境 \(s\) 下选择动作 \(a\) 的预期奖励。

策略变成：$\pi(a\mid s)$   。它表示在情境 \(s\) 下选择动作 \(a\) 的概率。
