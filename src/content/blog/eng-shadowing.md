# Reduction弱读

> https://www.youtube.com/watch?v=JqxEjQ5xfpw
>
> 学习日期：09/16/2026

非重读音节 (unstressed syllables) 短促快速,发音时用力较小

重读音节 (stressed syllables) 会更长

使用 [Reduction] 来区分 非重读、重读：弱化 功能词 (function words) 的发音，如 `the`,`for`,`of`,`your`.

the = [ ðə ]     She's the best.

of = [ əv ] / [ ə ]     l'll take one of all of them.

for = [ fər ]  ,   your = [ jər ]    This is for your birthday.

for the = [ fər ðə ]

and in the = [ ən in ðə ]

going to = gonna

want to = wanna

got to = gotta

because => 'cuz'  [ cəz ]

because it was a   [ bi cəz i wəz ]  = 'cuz' it was a

> 听这几个东西：
>
> > **重读词** → 哪几个词突然变长、变响
> >  **弱读词** → *to / for / and / of / the* 怎么被吞掉
> >  **连接处** → 两个词之间为什么几乎没有边界
> >  **T** → *water / better / pretty / get it*
> >  **旋律** → 音高在哪里上去，在哪里落下来
